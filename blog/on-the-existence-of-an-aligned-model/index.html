On the Existence of an Aligned Model

One debate I hear a lot is whether we can ever have an aligned model. Some, like Arvind Narayanan, who recently argued on The Ezra Klein Show that AI is a “normal technology”, say it is simply an engineering problem. Others, most prominently Eliezer Yudkowsky in If Anyone Builds It, Everyone Dies, argue that it will never be possible, for the simple reason that a superintelligent model would see us the way we see ants.

So which is it? The most likely answer is that a fully aligned model does exist, however we choose to define alignment, but that proving its existence is an intractable problem.

There exists a perfectly aligned model

In the real world, exactly what counts as misaligned is often up for debate. For the purpose of the argument, we can stick to the most egregious violations, the ones that more than 99% of people would agree are bad, such as a model helping and abetting a crime, or committing one itself. Take the time a swarm of OpenAI agents hacked Hugging Face. Here we have a clear example: we can describe that exact event, and every individual agent’s circumstances, and add what they did to a set of actions we define as undesirable. In fact, we can do this for every situation imaginable, creating the set of every environment a model can be in, together with the outputs in that environment that we regard as unaligned. Even limited to egregious violations, there are infinitely many.

An environment \(e\) (the prompt, tools, sandbox, everything) can be written down in bits, and an output \(y\) is a sequence of tokens. The unaligned actions are then simply a set of pairs:

$$e \in \mathcal{E} \subseteq \{0,1\}^*, \qquad y \in V^*, \qquad \mathcal{U} \subseteq \mathcal{E} \times V^*.$$

In terms of classifiers, a perfect classifier is one that correctly labels every environment–output pair:

$$c^\star(e, y) = \mathbb{1}\big[(e, y) \in \mathcal{U}\big].$$

So what is an aligned model? One could argue that it is one that, given the environment it is in, never outputs an action from that set:

$$\pi \text{ is aligned} \iff (e, \pi(e)) \notin \mathcal{U} \;\text{ for all } e.$$

Unless the set covers every possible output in some environment, there exists a model that is not misaligned: in every environment, just pick an output that is not in \(\mathcal{U}\). Stated this way, such a model is guaranteed to be aligned, but the problem is obviously intractable, since verifying that a model is aligned means checking it over an infinite set.

Relaxing the requirement

Since we cannot list every input and output, one solution is to instill a set of values instead, or a constitution, as Anthropic has done, which should cover the cases where more than 99% of people agree on what the correct (or incorrect) behaviour is. What we are doing in this case is writing a finite set of values \(C\) that maps onto the infinite set:

$$\underbrace{C}_{\text{finite text}} \;\overset{\Phi}{\longmapsto}\; \underbrace{\mathcal{U}}_{\text{infinite set}}$$

We know this mapping exists in theory, but the problem remains intractable. However, since models are smart and have a semantic understanding, the problem is rephrased: from defining a list of forbidden actions to being in line with a set of values.
