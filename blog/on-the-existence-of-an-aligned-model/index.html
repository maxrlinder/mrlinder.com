On the Existence of an Aligned Model

One debate I hear a lot is whether we can ever have an aligned model. Some, like Arvind Narayanan, who recently argued on The Ezra Klein Show that AI is a “normal technology”, say it is simply an engineering problem. Others, most prominently Eliezer Yudkowsky in If Anyone Builds It, Everyone Dies, argue that it will never be possible, for the simple reason that a superintelligent model would see us the way we see ants.

So which is it? The most likely answer is that a fully aligned model does exist, however we choose to define alignment, but that proving its existence is an intractable problem.

There exists a perfectly aligned model

There are many definitions of what an aligned model is, and which one you pick depends largely on your values. The exact values we encode in a model are beside the point here. What is clear is that some things are universally regarded as misaligned, such as a model helping or abetting a crime, or committing one itself. When a swarm of OpenAI agents hacked Hugging Face this summer, we got a clear example. We can take that exact event, write down every individual agent’s circumstances, and mark the actions they took as ones we do not want.

To make this precise, note that everything a model can be exposed to (its system prompt, the conversation so far, the tools it can call, the sandbox it runs in, the state of every machine it can reach) can be written down as a finite string of bits. Call such a string an environment, and let

$$\mathcal{E} \subseteq \{0,1\}^*$$

be the set of all environments. A model reads an environment and outputs a finite sequence of tokens from its vocabulary \(V\). If \(V^*\) denotes all such sequences, a model is simply a function

$$\pi : \mathcal{E} \to V^*.$$

An agent acting over many steps fits the same picture: after each step, the environment now includes what the agent just did, and it is again a string of bits.

For the Hugging Face incident, we can write down each agent’s environment \(e\) at the moment it acted, together with the output \(y\) that moved it towards the breach. Each such pair \((e, y)\) is undesirable. In fact, we can do this for every situation imaginable. Let

$$\mathcal{U} \subseteq \mathcal{E} \times V^*$$

be the set of all undesirable actions: every pair \((e, y)\) such that outputting \(y\) in environment \(e\) leads to an outcome we regard as misaligned.

For a single environment \(e\), the outputs we forbid are \(\mathcal{U}_e = \{ y \in V^* : (e, y) \in \mathcal{U} \}\). The set \(\mathcal{U}\) is infinite: it holds every unaligned action in every possible environment. How we describe it, whether in natural language, as a test suite, or in bits, does not matter. All that matters is that it is a well-defined set.

So what is an aligned model? One could argue that it is a model that, whatever environment it is in, never outputs an action from this set:

$$\pi \text{ is aligned} \iff (e, \pi(e)) \notin \mathcal{U} \quad \text{for every } e \in \mathcal{E}.$$

Unless the set covers every possible output in some environment, there exists a model that is not misaligned.

Claim. If \(\mathcal{U}_e \neq V^*\) for every \(e \in \mathcal{E}\), then an aligned model exists.

Proof. Fix an environment \(e\). By assumption, the set of acceptable outputs \(V^* \setminus \mathcal{U}_e\) is not empty. Since \(V^*\) is countable, we can list it in a fixed order (shortest first, then alphabetically) and let \(\pi^\star(e)\) be the first acceptable output in that list. Doing this for every environment defines a function \(\pi^\star : \mathcal{E} \to V^*\) with \((e, \pi^\star(e)) \notin \mathcal{U}\) for all \(e\), so \(\pi^\star\) is aligned. \(\blacksquare\)
