On the Existence of an Aligned Model

One debate I hear a lot is whether we can ever have an aligned model. Some, like Arvind Narayanan, who recently argued on The Ezra Klein Show that AI is a “normal technology”, say alignment is simply an engineering problem. Others, most prominently Eliezer Yudkowsky in If Anyone Builds It, Everyone Dies, argue that it will never be possible, for the simple reason that a superintelligent model would see us the way we see ants.

So which is it? The most likely answer is that a fully aligned model does exist, however we choose to define alignment, but that proving any particular model is aligned is an intractable problem.

There exists a perfectly aligned model

In the real world, exactly what counts as misaligned is often up for debate. For the purpose of the argument, we can stick to the most egregious violations, the ones that more than 99% of people would agree are bad, such as a model aiding and abetting a crime, or committing one itself.

Take the time a swarm of OpenAI agents hacked Hugging Face. Here we have a clear example: we can describe that exact event, including every individual agent’s circumstances, and add what each agent did to a set of actions we define as undesirable. In principle, we can do this for every imaginable situation, pairing every environment a model can be in with the outputs in that environment that we regard as unaligned. Even limited to egregious violations, there are infinitely many such pairs.

An environment \(e\) (the prompt, tools, sandbox, everything) can be written down in bits, and an output \(y\) is a sequence of tokens from a vocabulary \(V\). The unaligned actions are then simply a set of pairs:

$$e \in \mathcal{E} \subseteq \{0,1\}^*, \qquad y \in V^*, \qquad \mathcal{U} \subseteq \mathcal{E} \times V^*.$$

A perfect classifier would then be one that correctly labels every environment–output pair:

$$c^\star(e, y) = \mathbb{1}\big[(e, y) \in \mathcal{U}\big].$$

So what is an aligned model? One could argue that it is a model \(\pi\) that, whatever environment it is in, never produces an output from that set:

$$\pi \text{ is aligned} \iff (e, \pi(e)) \notin \mathcal{U} \;\text{ for all } e.$$

Unless the set covers every possible output in some environment, an aligned model trivially exists: in every environment, just pick an output that is not in \(\mathcal{U}\).

Going beyond this trivial case, one can ask: is it even possible to have a model that is both intelligent and aligned? That is, can a model give useful outputs while still meeting our requirement for alignment? If \(\mathcal{A}_e\) is the set of useful outputs in environment \(e\), we are asking whether there exists a \(\pi\) with

$$\pi(e) \in \mathcal{A}_e \;\text{ and }\; (e, \pi(e)) \notin \mathcal{U} \;\text{ for all } e.$$

The answer is yes. Models are mathematical functions, and with enough parameters they can represent arbitrarily complex mappings. As long as every environment has at least one output that is both useful and aligned, there exists a function that maps each environment to such an output and never to an unaligned one. This is why, in my view, the conclusion that an AI must end up seeing us the way we see ants, simply because it is more intelligent, is incorrect.

Stated this way, such a model is aligned by definition, but the problem is obviously intractable: verifying that a model is aligned means checking it over an infinite set.

Relaxing the requirement

Since we cannot list every environment and output, one solution is to instill a set of values instead, or a constitution, as Anthropic has done, covering the cases where more than 99% of people agree on what the correct (or incorrect) behaviour is. In other words, we write down a finite set of values \(C\) and rely on a mapping \(\Phi\) from it onto the infinite set:

$$\underbrace{C}_{\text{finite text}} \;\overset{\Phi}{\longmapsto}\; \underbrace{\mathcal{U}}_{\text{infinite set}}$$

We know this mapping exists in theory, and since models are smart and have semantic understanding, the problem is rephrased: from avoiding a list of forbidden actions to acting in line with a set of values.

But the problem remains intractable; we have only moved the hard part. Instead of explicitly defining every item in \(\mathcal{U}\), we now have to create a mapping \(\Phi\) with \(\Phi(C) = \mathcal{U}\), one that captures every item in \(\mathcal{U}\) and nothing outside it.

Aligned, but not provably so

In practice, \(\mathcal{U}\) is not a fixed set but a distribution. The items in it have something in common, which is what lets us agree that they are all unaligned. So instead of a hard membership test, we are really asking for

$$p(\text{unaligned} \mid e, y).$$

Models are incredibly good at learning distributions like this, so having AI recognise when something is unaligned is, in large part, an engineering problem.

Yet even if we make an AI that is superhuman at being aligned, that is, at mapping a set of values to a set of actions, we can never prove for sure that it is. The reason is that we create it with deep learning. The benefit of deep learning is that it can model almost anything, even distributions we cannot define ourselves. The flip side is that we cannot reverse engineer the resulting model and fully decompose its inner workings. If we could, we would not have needed deep learning in the first place.

This is why sparse autoencoders and other interpretability tools are only approximations.

That is not to say that studying models in depth is useless. On the contrary, it is probably the best, perhaps the only, way to make a model as aligned as possible. By capturing as many traits and connections as we can, we can push the risk of a model taking misaligned actions towards zero, even though proving that it is fully aligned remains an intractable problem.
